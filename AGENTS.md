# AGENTS.md

## Архитектура (КРИТИЧЕСКИ ВАЖНО)

- Все вычисления, расчёты, игровая логика, валидация — ТОЛЬКО на сервере.  
- Клиент отвечает только за отрисовку графики, ввод пользователя и отправку запросов на сервер.  
- Никогда не переносить серверную логику на клиент.  
- При любых изменениях сначала проверяй, где должна выполняться логика.

## Как работать

- Перед любой нетривиальной задачей составляй план и жди моего подтверждения.  
- После изменений всегда запускай тесты / проверку.
- Если задача большая — разбивай на маленькие шаги.
- При работе с UI, всегда сверяйся с файлом ui-new.md, где описаны правила интерфейса.
