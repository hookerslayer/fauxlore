# AGENTS.md

## Архитектура (КРИТИЧЕСКИ ВАЖНО)

- Все вычисления, расчёты, игровая логика, валидация — ТОЛЬКО на сервере.  
- Клиент отвечает только за отрисовку графики, ввод пользователя и отправку запросов на сервер.  
- Никогда не переносить серверную логику на клиент.  
- При любых изменениях сначала проверяй, где должна выполняться логика.

## Как работать

- Перед любой нетривиальной задачей составляй план и жди моего подтверждения.  
- После изменений всегда запускай тесты / проверку.
- После каждой задачи с новой миграцией применяй её к live-базе VPS (`fauxlore_production_candidate`, PostgreSQL 17 на `89.125.62.17:5433`, не к Supabase): сначала свежий бэкап, затем `psql --single-transaction -v ON_ERROR_STOP=1`, после — проверка результата.
- После каждой реализованной задачи выпускай релиз на VPS: собери bundle через `tools/build_vps_release.py`, проверь `tools/validate_release.mjs`, выложи новый каталог в `/opt/fauxlore/releases`, переключи `root` в nginx только после `nginx -t` и сохрани предыдущий релиз и конфиг для отката.
- Если задача большая — разбивай на маленькие шаги.
- При работе с UI, всегда сверяйся с файлом ui_new.md, где описаны правила интерфейса.
- Используй локальный браузер Codex для работы при необходимости. Не трогай другие браузеры пользователя.
