# Fauxlore — просмотр карты

Fauxlore — многопользовательская военно-политическая текстовая ролевая стратегия
в сеттинге фэнтези-миддлпанка. Игроки управляют государствами, судьи оценивают
приказы и публикации. Контекст работы и дальнейшие задачи: [ДЛЯ CODEX.md](ДЛЯ%20CODEX.md).

Старый проект подключён как submodule для изучения:

```powershell
git submodule update --init --recursive
```

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File tools/start-supabase.ps1
```

Открыть http://127.0.0.1:8004/ . Рабочая база, авторизация и серверные операции
находятся в Supabase; локально нужен только статический сервер. Скрипт собирает
публичные файлы в `.local/supabase-site` и запускает сервер без локального PostgreSQL.
Не раздавать корень репозитория обычным HTTP-сервером: `.local` содержит закрытые
экспорты и старые секреты. Устройство переноса и права: [supabase/README.md](supabase/README.md).

## Управление

- Перетаскивание карты мышью или одним пальцем — перемещение.
- Колесо мыши и жест двумя пальцами — масштабирование.
- Двойное нажатие — приближение. Ручных кнопок зума и «Вся карта» нет.
- «Информация → ID провинций» — подписи. На общем виде часть подписей скрывается
  для уменьшения наложений; при приближении появляются остальные.
- «Информация → Поиск»: ID и «Найти» (или Enter) — переход и выделение.
- Нажатие на провинцию — полный список игровых параметров. Admin может включить
  режим редактирования в панели «Администрирование»; население задаётся напрямую.
  Игрок переименовывает провинции своего государства после того,
  как оператор привяжет аккаунт к государству.
- Все панели изначально свёрнуты в квадратные Lucide-иконки.
- «Инструменты»: две точки для расстояния, контур для площади, координаты и переход.
- «Авторизация»: вход через Google; первый вход создаёт аккаунт игрока.
  Роль admin назначается оператором в закрытой таблице базы.
- Стиль всего UI закреплён в [UI_STYLE.md](UI_STYLE.md).

`index.html`, `viewer.css`, `viewer.js`, `ui.js`, `map-tools.js` — интерфейс карты.
Метаданные и настройки берутся через Supabase RPC из PostgreSQL; `provinces.json`
служит источником геометрии, но не заменяет актуальные игровые данные в облаке.
Для рендера нужен
WebGL 2. Видимые тайлы загружаются в массив текстур плитками до 2048×2048; цвет и новые
границы вычисляются шейдером. ID считывается с GPU одним пикселем без полной
CPU-копии изображения. Подписи отрисовываются на Canvas размера экрана.

Карта ограничена начальной игровой областью из `map-data/view-region.json`.
Реки и рельеф встроены в тайлы; рельеф накладывается через Multiply с opacity 60%.
Глобально 5716 провинций: суша, море и озёра. Поиск и общий вид ограничены регионом.

Подготовка маски описана в [tools/MAP_PIPELINE.md](tools/MAP_PIPELINE.md).
