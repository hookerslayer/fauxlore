# Fauxlore — просмотр карты

Fauxlore — многопользовательская военно-политическая текстовая ролевая стратегия
в сеттинге фэнтези-миддлпанка. Игроки управляют государствами, судьи оценивают
приказы и публикации. Контекст работы и дальнейшие задачи: [ДЛЯ CODEX.md](ДЛЯ%20CODEX.md).

Старый проект подключён как submodule для изучения:

```powershell
git submodule update --init --recursive
```

Из корня проекта:

```powershell
python -m http.server 8001
```

Открыть http://localhost:8001/ . Если используется другой порт, заменить его
в адресе. Сервер должен обслуживать папку `fauxlore`, а не вложенный
`sixiemeterre_northeast`.

## Управление

- Перетаскивание карты мышью или одним пальцем — перемещение.
- Колесо мыши, жест двумя пальцами и кнопки +/− — масштабирование.
- Двойное нажатие — приближение; «Вся карта» — возврат к общему виду.
- «Показать ID» — подписи провинций. На общем виде часть подписей скрывается
  для уменьшения наложений; при приближении появляются остальные.
- Ввод ID и «Найти» (или Enter) — переход к провинции и выделение.
- Нажатие на провинцию — её ID, тип и площадь в пикселях исходной маски.
- Кнопка в заголовке сворачивает панель; на узком экране она изначально свёрнута.

`index.html`, `viewer.css`, `viewer.js` — самостоятельный статический просмотрщик.
Он использует `map-data/province-ids.png` и `map-data/provinces.json`, не требует
старой базы данных, исходной подложки или внешних библиотек. Для рендера нужен
WebGL 2. Маска загружается в массив текстур плитками до 2048×2048; цвет и новые
границы вычисляются шейдером. ID считывается с GPU одним пикселем без полной
CPU-копии изображения. Подписи отрисовываются на Canvas размера экрана.

Подготовка маски описана в [tools/MAP_PIPELINE.md](tools/MAP_PIPELINE.md).
