# Обязательный стиль UI Fauxlore

Согласовано пользователем 19.10.2026. Применять ко всему новому интерфейсу,
включая будущие игровые разделы. Не возвращать сине-серые панели.

- Фон поверх карты: **чёрный с непрозрачностью 60%**, `rgba(0,0,0,.6)`.
- Акцент: жёлтый, `#e7c667`; текст нейтральный светлый, вторичный — серый.
- Единые переменные `--ui-*` в `viewer.css`; радиус 8px, промежуток 8px,
  внутренние отступы 8/12/16px по контексту.
- Панели изначально свёрнуты в небольшие квадратные кнопки с Lucide-иконками.
- Слева: Авторизация, Меню, Легенда. Справа: Управление, Маркеры, Информация,
  Инструменты, Администрирование (только роль admin).
- Одна боковая панель раскрыта за раз. Ширина и колонки подстраиваются под
  содержимое и экран, без горизонтальной/вертикальной прокрутки. Если целая
  панель не помещается, логические группы доступны через компактные вкладки.
- Доки кнопок: 12px от верхних углов. Карточка объекта: 12px от левого нижнего
  угла. При пересечении с масштабом сначала сужается (не меньше 160px),
  только на совсем узком экране поднимается над ним.
  Раскрытые панели не перекрывают календарь, масштаб и карточку объекта.
- Меню занимает почти весь экран с отступом 12px. Вкладки меню всегда идут
  одной вертикальной колонкой и прокручиваются отдельно при нехватке высоты.
  Ширина колонки определяется самой длинной подписью с небольшим запасом под
  полосу прокрутки; у области вкладок общий тёмный фон. Шрифт кнопок 12px.
  При раскладке меню сначала сохранять максимум места содержимому выбранной
  вкладки.
- Поиск ID находится в «Информация», а не в «Управление».
- Плашка `1452 год / 1 ход` сверху по центру постоянна; снизу по центру масштаб.
- Данные карты/рельефа не перекрашивать ради изменения палитры UI.
- В легенде: «Нейтральные территории», «Море», «Озеро». Озёра на карте залиты
  тем же цветом, что реки: #1f87ad. Типы и ID озёр сохраняются.
- Lucide SVG хранятся локально в `assets/icons/`, лицензия рядом.

При заданной калибровке один исходный пиксель занимает 1 km², сторона — 1 km.
Расстояния отображать в km, площади — в km². Подпись площади у масштабной
полоски означает квадрат со стороной, равной длине полоски.
