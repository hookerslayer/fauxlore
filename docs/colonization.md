# Колонизация

## Тип провинции после колонизации

При успешном завершении колонизации провинции ей сразу присваивается тип
`Территориальная`. Пока колонизационная механика не реализована, это правило
зафиксировано как требование к будущему действию колонизации: установить тип
в той же транзакции, в которой провинция становится владением государства.

Тип провинции определяется с таким приоритетом:

1. На провинции есть маркер столицы → `Столичная`.
2. Иначе на провинции есть маркер города → `Городская`.
3. Иначе, если провинция только что успешно колонизирована → `Территориальная`.
4. Во всех остальных случаях → `Регион`.

Если столица и город одновременно отмечены на одной провинции, побеждает тип
`Столичная`. Удаление маркера должно немедленно пересчитать тип по оставшимся
условиям. Колонизационное действие должно устанавливать `Территориальная`
только для провинции без маркера столицы или города.

Срок, в течение которого провинция считается «только что колонизированной»,
и игровое событие, после которого она становится регионом, отдельно не
определяются этим правилом и должны быть согласованы при проектировании
колонизационной механики.
