# Колонизация

## Тип провинции после колонизации

При успешном завершении колонизации провинция без маркера города или столицы получает тип `Регион`. Отдельного типа для недавно колонизированной земли нет.

Тип провинции определяется с таким приоритетом:

1. На провинции есть маркер столицы → `Столичная`.
2. Иначе на провинции есть маркер города → `Городская`.
3. Во всех остальных случаях, включая недавно колонизированные земли, → `Регион`.

Если столица и город одновременно отмечены на одной провинции, побеждает тип
`Столичная`. Удаление маркера должно немедленно пересчитать тип по оставшимся
условиям. Колонизационное действие устанавливает тип в той же транзакции, в которой провинция становится владением государства.

При недостатке 1 000 G на очередное содержание колонизация срывается; провинция остаётся нейтральной и доступна для новой попытки со следующего хода.
