# Правила интерфейса Fauxlore

Эти правила обязательны при создании и изменении любого UI проекта.

## Компоновка

- Между самостоятельными блоками всегда должен быть визуально заметный отступ. Не размещать соседние карточки, панели, формы и таблицы вплотную.
- Если блок не содержит большой объём текста или широкую таблицу, не растягивать его на всю ширину контейнера. Выбирать компактную ширину и группировать связанные элементы.
- Кнопки внутри вкладок меню не растягивать на всю ширину контейнера. Располагать их компактно рядом с содержимым; на мобильном экране сохранять удобную область нажатия.
- Ширину на всю область использовать только там, где это нужно содержимому (например, большой таблице или длинному тексту), а не по умолчанию.

## Единые возможности

- Любое действие с игровыми данными, доступное игроку, должно быть доступно администратору при просмотре соответствующего государства. Администраторские инструменты сверх этого правила могут оставаться отдельными.
- Изменения формы сохранять явной кнопкой «Сохранить», если пользователь редактирует несколько связанных значений в одном разделе; не отправлять каждое поле отдельно без указания.
- Компактность не должна ухудшать читаемость: таблицам разрешено горизонтально прокручиваться на телефонах, а подписи и элементы управления должны оставаться различимыми.
